あそびかた

🧭 移動：W / ↑で前進、S / ↓で後退。A・D / ←・→で向きを変える。

🧺 素材：木・石・花に近づいてE。海・湖・川では魚を捕まえたり泳いだり、Bキーかボートボタンで乗船。Eで降りられるよ。

💰 お店と銀行：資材屋で素材を購入。銀行で資源を売り、ATMで財布と口座のお金を移せるよ。

🚙 車：車ショップで購入して、車道か駐車場でE。W/Sで走り、A/Dで曲がり、Eで乗り降り・駐車。

🌏 外国：飛行場から飛行機、船乗り場から船で短時間移動。海をボートで渡るか、道路を車で走っても行けるよ。

↻ 建築：「つくる」から建物を選び、地面をクリック。道路・駐車場はRキーまたは回転ボタンで回せるよ。

🗺 地図：ホーム島と外国、道路、建てた施設、自分の位置を表示するよ。

⬆ ジャンプ：Space または画面のジャンプボタン。
