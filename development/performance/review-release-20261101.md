# 復習日と５分モード（2026-11-01）

依頼受領13:51JST、追加の一括実施指示13:52JST。無料のみの方針を維持。元の予定⑮・⑯のうち、既存のデッキのフラッシュカードに実装できる範囲を制作。

## 使い方

デッキで「フラッシュカード」を開く。「出題するカード」の「復習する日になったカード」で予定が来た判定済みカードだけを出題する。初めて判定するカードは従来の「すべて」「未習得」から学べる。

「今日は５分だけ」を選び、「この条件で開始」を押すと開始。画面を離れた間とノート表示に切り替えた間は計測しない。５分経過後は今のカードの判定を待って終了する。短く終えてもそれまでのカード判定は残る。終了時に保存失敗を成功と表示しない。

## 記録

既存のブラウザー／アカウント／デッキ別キーを維持してversion2に拡張。旧version1の判定を引き継ぐ。新しく保存するのはID、改訂判別のハッシュ、自己判定、復習段階、予定時刻、判定日。問題文・答え・メールアドレス・認証情報は保存しない。元のアクセス権はデッキAPIで確認し、この記録から権限やポイントは付与しない。

覚えた→１日、復習予定後に覚えた→３日、７日、14日、30日。その後は30日。期日前の繰り返し判定では予定・段階を変更しない。もう一度は段階０で即時に復習対象となる。カードの改訂が変わると旧判定を適用しない。タイムゾーン表示は日本時間で明記。

## 検査

- スケジュール：各間隔、期日前の繰り返し、もう一度によるリセット、不正な段階／日時、日本の日付境界。
- UI：旧記録移行、予定日前後の抽出、問題文の安全なテキスト表示、本文を保存しないこと、アカウント・カード改訂の分離。
- ５分：残り4分59秒の表示、非表示中の停止、時間経過後も現在カードを表示、判定後の終了、ポイントイベントは通常通り１件、記録クリア時のタイマー破棄、容量不足時の警告。
- JS構文検査、公開先でのファイル一致。

これらは制御した日時・保存領域・DOMの模擬検査。実アカウントでのログインから学習までのブラウザー操作は未確認。課金AI、外部サービスの追加、DB変更は行っていない。
