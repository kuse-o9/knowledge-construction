# 専用管理画面と文字の読みやすさ

依頼受領：2026-11-07 21:46 JST。無料の既存構成で実装。

## 実装

- 管理者ホームは機能への入口。削除申請、デッキ編集、アカウント削除申請、アカウント管理、オーナー操作、履歴を別URLに分離。
- 既存のadmin_bootstrapによる本人確認済みHTML／モジュールを再利用。フォームID・保存・削除承認のAPI契約は維持。選んだ画面の一覧だけを初期取得し、関係のない一覧は読み込まない。
- オーナー専用ページはサーバーが返すownerが真の場合のみ表示。管理者追加・解除と処理待ち解除のボタンはこの画面に集約。サーバー側の認証・管理者専用パスワード・権限判定・監査は変更していない。
- 将来サーバーモジュールの構成が変わったときは、一致しないコードを無理に加工せずエラーを表示する。各専用画面で既存モジュールが使う非表示の補助DOMを保持するが、その一覧は読み込まない。
- ホームから行ける学習・交流・管理画面の文字、フォーム、補足表示を調整。ゲームの部屋、車両基地、鉄道ゲームの操作盤、こもれび島、動画編集も共有の軽いCSSで文字・見出し・操作状態を読みやすくした。描画・模型・音声・保存処理を変更しない。
