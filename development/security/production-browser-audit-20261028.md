# Study Note 実アカウント・本番セキュリティ再検査
実施日：2026年10月28日（日本時間）

## 判定
**検査した範囲は合格。新たに発見した1件を本番で修正し、対象経路を再検査しました。ただし、全面的な全機能検査の完了・脆弱性ゼロの保証ではありません。**

対象は Study Note の公開画面、リポジトリのローカルソース、Supabase の Study Note プロジェクトのみ。他サービスへの侵入・負荷試験・実利用者のパスワード推測は行っていません。

## 新たに発見した問題と修正
フィードバックの一覧・統計・他人の詳細を取得する経路で、管理者資格のみを確認し、管理者専用パスワードの確認状態を要求していませんでした。画面のアクセス制限と別に、APIから取得できる条件が残っていた問題です。

本番DBの一時フィードバックで再現し、実利用者の他人の内容を取得せず確認しました。
- study-api が検証済みトークンから得た session_id をサーバー内部で付与します。利用者入力の値では置き換えられません。
- service_role 専用の study_feedback は、管理者操作について有効な Auth セッションと専用パスワード確認記録を照合します。
- 本人が自分のフィードバックを読む操作は維持します。
- DBマイグレーション 20261028041710_require_admin_password_for_feedback_reads を適用。
- study-api バージョン17を本番配信。verify_jwt=true を保持。配信後にコードが修正版と一致することを再取得で確認。

## サーバーと本番DBでの再検査
本番DBのトランザクション内で一時データを作成し、すべて ROLLBACK。DB内のJWT claims設定を使う検査は、署名付きJWTでのブラウザー/API検査とは区別します。

| 検査群 | 結果 |
|---|---|
| 既存修正の回帰 | 専用確認なし・別セッション・期限切れ・旧パスワード版・失効Authセッションを拒否。有効な確認状態は許可 |
| 旧ゲーム管理API | 未確認状態で他プレイヤー一覧・資源追加を拒否 |
| フィードバック修正 | 未確認管理者の他人の詳細・全体一覧・統計を拒否。本人の詳細/一覧は許可。確認済み管理者は許可。Authセッション失効後は拒否 |
| 個人デッキの所有権 | 別アカウントによる取得・編集・削除・問題追加を拒否 |
| 編集競合 | 古いrevisionによる上書きを拒否 |
| 上限 | 1人10デッキ、1デッキ150問を超える追加を拒否 |
| オーナー保護 | オーナーの本人アカウント削除不可を確認。実削除は未実施 |
| セーブの分離 | 他人のセーブの参照・更新は0行。匿名の参照権限なし、クライアントのTRUNCATE権限なし |
| 内部APIとスキーマ | 重要なservice_role専用RPCをanon/authenticatedから実行不可。study_privateへの両ロールのUSAGEなし |
| DB/Storage | 対象public/privateテーブルのRLS無効件数0。画像・フィードバックの両バケットは非公開。publicビューなし |
| 修正後の本番再検査 | 上記の既存修正とフィードバックの攻撃条件を再実行し合格 |

ダウンロードした本番ハンドラーのローカル検査：
- 既存の認証/専用パスワード/CORS/メンテナンス検査：18項目合格。
- 新規回帰検査：27項目合格。19種類の未確認管理操作の拒否、session_idの入力偽装防止、DBの拒否結果のHTTP403化、不正認証のHTTP401化など。
- 外部Auth/DBはモック。この45項目を実ブラウザーの45回の侵入成功/失敗とは数えません。
- Node標準のTypeScript変換を使い、外部パッケージ追加や有料AI実行なし。

ローカルソース検査：対象拡張子 js/ts/html/json/md/sql、2MB以下、node_modules/.git除外の287ファイルで、secretキー形式とservice_role JWTを検索。該当なし。現在のGitHub全履歴や全バイナリの秘密情報不存在を保証する検査ではありません。

## 残った条件・未確認事項
1. 現在の実アカウントは3件すべて管理者で、一般利用者の実アカウント2件がありません。**一般利用者同士のブラウザー切替による所有権検査は未完了**です。DB内の別アカウント検査で代替した範囲は上記に限定します。
2. 現在は予約メンテナンスが有効です。オーナー以外の通常学習を実ブラウザーで検査するには、通常利用を安全に試せる検証環境と専用テストアカウントが必要です。現行のメンテナンス予約を検査の都合で解除していません。
3. 登録/確認メールの到達、パスワード再設定、実アカウント削除、他人のBAN/権限変更、実データの削除承認、公開内容の変更、全画像形式のアップロードと悪性ファイルの網羅検査、全画面のアクセシビリティ/端末互換/負荷/全ゲーム動作などは完了していません。実データに不可逆な影響を与える検査は行っていません。
4. 署名付きトークンを持つ複数実アカウントでの、全APIに対する網羅的なHTTP侵入テストは未完了です。今回の本番再侵入テストは、上記の問題と権限経路に限定した再現・修正確認です。
5. Supabase Advisor は意図的なSECURITY DEFINER APIとdefault-denyのprivateテーブルについて警告/情報を引き続き表示します。これらを消すための権限拡大はしていません。
6. 漏洩パスワード照合は未有効化。Supabase公式ではPro以上の機能とされ、課金契約やプラン変更は行っていません。
7. GitHub Pagesと公開リポジトリは静的ファイルの秘密保管先ではありません。既に公開・コピー済みのデータは回収できません。現在は全ゲームが公開中です。
