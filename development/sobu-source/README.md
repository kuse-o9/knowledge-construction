# 総武線快速 編集用ソース

東京〜千葉10駅・両方向。E235系1000番台を参考にした青・クリーム色の簡易模型、11両、4・5号車相当の2階建てグリーン車。方向転換で編成順も切り替える。

## 再構築

`python development/tools/restore-sobu-models.py` で公開用データから大きな模型ソースを復元する。

`python development/tools/build-sobu.py` で `sobu.html` と `sobu-data-*.bin` を再生成する。模型のJSはGitでは重複保存せず、復元可能な公開用データに保管する。

`rail-data.js` はOSM 9475339の線形、`route-source.osm` は取得した元のOSMデータ。加工・共有はODbL-1.0。街と駅は着色済み共通簡易模型を再利用。公式建物の精密再現ではない。

## 今回の調査と実装

- 乗換路線：JR東日本の東京近郊路線図・総武房総路線図、東京メトロ、都営交通、京成松戸線の公式情報。`announcement-source.json` に出典を保存。
- 東京・新日本橋・馬喰町は地下。地下深さは近似値。駅前後の壁と天井を設置し、屋外カメラは地下区間で運転席位置に切り替える。
- 並走する中央・総武線各駅停車を黄色の10両で周期運転。既存のOSM線形・地形を利用。両方向に運転し、ラッシュ・平日・休日で密度を切り替える。実ダイヤではない。
- 既制作の快速・緩行線模型の干渉を防ぐため、並走線の表示間隔を24m調整。正確な実配線・線路間隔ではない。
- すべての乗換先の地上・地下構造や周辺列車を再現できたわけではない。今版の周辺列車は総武線の対向列車と中央・総武線各駅停車。京成・東武等の周辺列車、各駅固有の建築は追加調査・制作が必要。

## 検査

`../sobu-corridor-audit.json` と `../sobu-camera-audit.json` に全区間の検査結果を保存。

- 両方向の全10駅、フリーラン・時刻運転で終点まで走行計算。全停車位置で0km/h、ドア動作、通過ミス0を確認。
- 全区間2m間隔、ホーム前後1m間隔、3高さ×3横位置、404,829本の前方レイで模型干渉0。
- 運転席位置39,761点、車外カメラ36,320点。運転席ピッチ最大約4.31度。車外カメラの地形余裕は最小約51.1m。建物との干渉0。
- 全20方向別ホーム、日英の言語タグ、乗換情報、並走列車の進行、地下でのカメラ切替をUI模擬環境で検査。
- 車両基地の6台すべてを実際の投影座標でクリック判定。
- 実ブラウザ/GPUでの全線映像検査は未実施。数値検査のみを根拠に実写同等・完全再現とはしない。
