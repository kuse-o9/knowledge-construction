- `fallback-ui-report.json`：Chromium 151でWebGLを意図的に無効化したフォールバック操作検査。既存5ゲームの起動、地図、手動、非常、区間引継ぎ、青梅の歩行/明示的乗車、大月の編成変更、390px表示、Web Audioの開始/警笛/音量/停止を確認。ブラウザエラーなし。UIの接続検査ではテスト内で終点状態を設定する。全駅の実時間走行の代わりにはしない。

ブラウザスクリプトはPlaywrightを使用する。`BAYLINE_CHROMIUM` に実行ファイルのパスを設定できる。公開URLへのリクエストを手元のリポジトリの同名ファイルへ差し替え、現在の成果物を検査する。外部のCesium/地形は通常の配信元へアクセスする。

実機GPU、合成音声の読み方/音質、実際のスピーカー出力、タッチ端末の感触、現地の信号・配線の測量照合は未確認。ソフトウェアWebGL・音声APIの動作をこれらの合格と混同しない。
