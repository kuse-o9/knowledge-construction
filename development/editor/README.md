# Studio Note — 基本編集版

2026-10-25。既存Study Noteの `/editor/index.html` に統合。

## 公開対象

- 動画・写真・音声をローカル読み込み、映像を順に結合。
- 時間・元素材の開始位置・再生速度、分割・削除・並べ替え。
- テロップ、文字色・サイズ、明るさ・コントラスト・鮮やかさ、音量と短い音声フェード。
- 1080pの横・縦・正方形を元素材から実時間でWebM書き出し。対応ブラウザーが必要。
- JSONプロジェクトのダウンロード・再読込。素材そのものは保存されないため再選択で接続。
- 50種類の60秒オリジナル合成BGMと32種類の合成効果音。選択時だけ生成し、初期転送を増やさない。生成音源は無料で商用動画にも利用可能。
- 40操作の取り消し、キーボードの再生／停止、スマホ幅の表示。
- 管理者専用パスワードの確認後に使えるAI利用承認画面。通常1回、明示承認済み5回、オーナー無制限。管理者権限だけでは利用枠は増えない。追加枠申請の決定はオーナーのみ。日本時間の日付を使用。

## 未完成の範囲

AI補正の外部処理サービスとサーバー用認証情報は未設定。AI処理の実行ボタンや成功の擬似表示はなく、枠確認・申請・承認だけを提供する。接続するまで回数は消費されない。将来のEdge処理ではサービス専用RPCで先にジョブを予約し、成功／失敗を一度だけ確定する。失敗ジョブは日次利用数に含めない。

DaVinci Resolveの全機能との互換・同等性はない。高度な合成、カラー管理、字幕ファイル、複数映像トラック、トランジション等は今後の拡張。MP4/H.264書き出しは未対応。

## 検証

実ブラウザーで画像・動画・音声生成、時間変更・分割、文字・取り消し、プロジェクトJSON、WebM実書き出し、390px幅を確認。出力ファイルをffprobeでVP8/Opus/1920x1080として確認。PGliteで既存の認証・管理者本人確認のfixtureを使った13チェックに合格。本番RPCでは匿名による枠取得／操作の拒否を確認。実利用者の承認状態や回数は検査目的で変更していない。
