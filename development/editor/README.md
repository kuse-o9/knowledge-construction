# Studio Note — ローカル動画編集

更新：2026-10-26。既存Study Noteの `/editor/index.html` に統合。AI補正は利用者の指示により削除。

## 提供する機能

- 動画・写真・音声のローカル読み込み、分割、切り取り、結合、並べ替え、速度変更。
- 主映像と重ね映像、文字、不透明度・位置・大きさ・回転・フェード、矩形切り抜き、開始/終了の線形アニメーション。
- 手動の明るさ・コントラスト・鮮やかさ、音量・3帯域EQ・ハイパス・圧縮。
- SRT字幕の読み込み/書き出し、複数行、取り消し/やり直し、複製。
- プロジェクトJSONの保存/読込と素材の再接続。素材そのものはJSONに保存しない。
- 50種類の60秒オリジナル合成BGMと32種類の合成効果音。選んだときだけ生成。
- 1080p/4K横・縦・正方形のWebM、対応環境のネイティブMP4、書き出し中止。元の素材から実時間で生成。MP4のコーデックはブラウザー依存（検査環境はVP9/Opus、H.264/AACの保証なし）。

## AI補正の削除

AI補正・接続確認・利用枠・追加申請・管理者の利用承認入口は削除。旧管理者URLは提供終了案内だけを表示し、操作やRPCを実行しない。旧サーバーURLは410を返す停止用コードへ置換し、外部AIへの送信・秘密キー参照・課金処理を含まない。古い画面がキャッシュに残っていても補正リクエストは停止される。通常の編集と既存の補正値を含むプロジェクトは利用可能。

保存済みの秘密キーや過去の利用履歴を勝手に削除する変更ではなく、過去の料金やこのアプリ以外でのキー利用は未確認。AI補正を新たな指示なしに復活させない。

## 検証と残る範囲

停止用ハンドラーの各HTTP要求、公開エンドポイントの410、AI操作の不存在、手動色調整の実描画、プロジェクト保存、旧管理者ページの無操作を検査。既存の字幕・重ね映像・フェード・書き出し・スマホ幅もブラウザーで回帰検査する。

DaVinci Resolveの全機能と同等ではない。未完成項目は `resolve-feature-matrix.md`。削除済みのAI補正は未完成項目として復活させない。
