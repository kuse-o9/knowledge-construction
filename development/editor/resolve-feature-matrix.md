# 機能対応表（2026-10-25）

対象は、素材整理・編集・合成・カラー・音声・書き出しを分かりやすく一体化すること。Blackmagic Design公式の製品説明を基準に整理する。単一のAI呼び出しをもって全機能同等とは扱わない。

参照：https://www.blackmagicdesign.com/jp/products/davinciresolve/

| 分野 | 実装済み | 未完成 |
|---|---|---|
| 素材 | ローカル動画・写真・音声、素材不足時の再接続 | ビン・メタデータ検索・プロキシ管理・RAW/専門形式 |
| 編集 | 切り取り・分割・順序変更・複製・取り消し・やり直し・速度指定 | リップル/ロール/スリップ編集、マルチカム、ネスト、速度ランプ |
| レイヤー | 主映像＋重ね映像、音楽・文字の重ね合わせ | 任意数の独立映像トラック・トラックミキサー |
| 画面調整 | 位置・大きさ・回転・不透明度・フェード | マスク・クロップ・手ぶれ補正・キーフレーム曲線 |
| 字幕 | SRT入出力・文字色・サイズ・複数行 | 自動文字起こし、音声に合わせた字幕生成、多形式字幕 |
| カラー | 明るさ・コントラスト・鮮やかさ、AIによる補正値提案コード | HDR/ACES/色空間管理・カーブ・スコープ・LUT・ノード |
| 合成 | 基本レイヤー重ね | Fusion相当ノード合成、3D、粒子、トラッキング |
| 音声 | 音量・短いフェード・3帯域EQ・ハイパス・圧縮、50種類BGMと32種類効果音の生成 | AIノイズ除去・自動ミックス・録音・サラウンド |
| AI補正 | 認証、明示同意、代表画像1〜3枚、サーバー日次枠、失敗時の返却 | サービス用キー登録と実プロバイダーでの最終検査。AI超解像・ノイズ除去等は未実装 |
| 保存 | プロジェクトJSONのダウンロードと読込 | 自動保存・共同作業・クラウド同期 |
| 出力 | 元素材からの1080p/4K横・縦と正方形WebM、対応環境のネイティブMP4、書出し中止 | ProRes/DNxHR、8K/HDR、バッチ/非実時間書出し |

ブラウザーのメモリー、GPU、コーデック対応により制約がある。機能を「実装済み」とするには、実際の入出力まで検査する。今の版をDaVinci Resolve全機能と同等の完成品とは表記しない。

MP4のコーデックはブラウザー依存。検査環境ではVP9/OpusのMP4コンテナーで、H.264/AAC互換は確認していない。4Kは3840×2160の実ファイルを検査。
